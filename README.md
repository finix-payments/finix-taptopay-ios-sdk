# FinixTapToPaySDK

The official Finix iOS SDK for accepting contactless payments using Apple's Tap to Pay on iPhone feature.

## Installation

### Swift Package Manager

Add the following to your `Package.swift` file:

```swift
dependencies: [
    .package(url: "https://github.com/finix-payments/finix-taptopay-ios-sdk.git", from: "1.0.0")
]
```

Or add it through Xcode:
1. File > Add Package Dependencies
2. Enter: `https://github.com/finix-payments/finix-taptopay-ios-sdk.git`
3. Select version requirements
4. Add to your target

## Requirements

- iOS 18.1 or later
- iPhone XS or newer
- Swift 5.9+
- Xcode 16.0+
- Active Finix merchant account
